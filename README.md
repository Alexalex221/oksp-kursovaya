# Сервис выдачи книг в библиотеке

Учёт выдачи книг на абонементе: библиотекарь выдаёт экземпляр читателю, принимает
возврат, видит просрочку и штраф, а сводка показывает, сколько книг на руках,
сколько из них просрочено и какие книги берут чаще прочих. Учебный сервис
курсовой работы по дисциплине «Оптимизация клиент-серверных приложений», вариант 1.

Правила:

- экземпляр выдаётся, только если он свободен и у читателя нет просроченных выдач;
- срок пользования — 14 дней, при возврате фиксируется дата;
- просрочка — дни между сроком возврата и фактической датой (для невозвращённой
  книги — по сегодняшний день), штраф — 10 ₽ за день просрочки.

## Требования

- Docker 29 с Compose v2 — всё остальное работает в контейнерах;
- образы: `python:3.12-slim` (Python 3.12, FastAPI 0.115, SQLAlchemy 2.0 + asyncpg),
  `postgres:16-alpine`.

## Установка и запуск

    git clone https://github.com/Alexalex221/oksp-kursovaya.git
    cd oksp-kursovaya
    cp .env.example .env
    docker compose up -d --build
    docker compose exec api python db/manage.py schema
    docker compose exec api python db/manage.py seed small

Рабочее наполнение (100 000 выдач, до минуты) вместо малого:

    docker compose exec api python db/manage.py seed work

Наполнение воспроизводимо: перед загрузкой таблицы очищаются, генератор работает
от постоянного зерна и фиксированной даты, повторный запуск даёт ту же базу.
Число записей по таблицам:

    docker compose exec api python db/manage.py counts

| Таблица  | Малое | Рабочее |
|----------|------:|--------:|
| readers  |    50 |   3 000 |
| books    |   100 |  10 000 |
| copies   |   200 |  30 000 |
| loans    |   300 | 100 000 |

## Проверка работоспособности

Интерфейс открывается по адресу http://localhost:8081, учётная запись —
`librarian` / `librarian`. После входа открывается список выдач; карточки
выдачи, читателя и книги открываются по ссылкам, сводка — пунктом «Сводка».

## Тесты

    docker compose exec api pytest

Тесты операций создают и наполняют собственную схему `<PREFIX>_test`, рабочие
данные не затрагиваются.

## Программный интерфейс

Все операции, кроме входа, требуют сеансовой куки `library_session`, без неё
отвечают 401. Ошибки возвращаются как `{"detail": ...}`. Даты — `ГГГГ-ММ-ДД`.

| Метод и путь                  | Параметры                                                  | Ответ                                                                                   | Ошибки        |
|-------------------------------|------------------------------------------------------------|-----------------------------------------------------------------------------------------|---------------|
| POST /api/login               | тело: login, password                                      | 200, учётная запись `{id, login, full_name}` и сеансовая кука                            | 401, 422      |
| POST /api/logout              | —                                                          | 204                                                                                     | —             |
| GET /api/me                   | —                                                          | 200, текущая учётная запись                                                             | 401           |
| GET /api/loans                | page ≥ 1, size 1–100, status (active, overdue, returned), reader_id, book_id | 200, `{items: [выдача], total, page, size}`, новые выдачи первыми                | 401, 422      |
| GET /api/loans/{id}           | —                                                          | 200, выдача                                                                             | 401, 404      |
| POST /api/loans               | тело: copy_id, reader_id                                   | 201, созданная выдача                                                                   | 401, 404, 409, 422 |
| POST /api/loans/{id}/return   | тело (необязательно): returned_on, по умолчанию сегодня    | 200, закрытая выдача с просрочкой и штрафом                                             | 401, 404, 409, 422 |
| GET /api/readers              | page, size, q — часть ФИО                                  | 200, `{items: [читатель], total, page, size}`                                           | 401, 422      |
| GET /api/readers/{id}         | —                                                          | 200, читатель, `stats {loans_total, on_hands, overdue, fines_total}`, все его выдачи     | 401, 404      |
| GET /api/books                | page, size, q — часть названия или автора                  | 200, `{items: [книга и число экземпляров], total, page, size}`                          | 401, 422      |
| GET /api/books/{id}           | —                                                          | 200, книга, `loans_total`, экземпляры с состоянием `free` / `on_loan` и текущей выдачей  | 401, 404      |
| GET /api/summary              | —                                                          | 200, `{on_date, copies_total, on_hands, overdue, overdue_share, top_books[10]}`          | 401           |

Выдача — `{id, issued_on, due_on, returned_on, status, overdue_days, fine, reader {id, full_name}, copy {id, inventory_no}, book {id, title, author}}`.

Код 409 — отказ по правилам: экземпляр уже выдан, у читателя есть просроченные
выдачи, выдача уже закрыта, дата возврата раньше выдачи или в будущем.
